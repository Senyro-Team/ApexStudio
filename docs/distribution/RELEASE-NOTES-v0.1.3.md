# Apex Studio v0.1.3

This update improves Roblox and ERLCX livery workflows, project organization, team sync and preview exports.

## Highlights

- Added `.apexpreview` export for compatible job vehicle liveries, with format documentation for preview tools.
- Improved ERLCX draft creation and publishing, including carrying project livery colors through imports and browser handoff.
- Added livery-folder filters to Roblox and ERLCX upload pickers and improved project livery management for commission workflows.
- Fixed team sync handling for trashed livery-slot replacements and improved reliability for older sync data.
- Updated the CLI and extension to support the improved livery and publishing workflows.

## Upgrade

Run the Windows installer to install or update Apex Studio. Existing `0.1.1` and `0.1.2` installations can also receive this version through **Settings → Updates**.
