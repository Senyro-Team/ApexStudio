# Apex Studio v0.1.2

This release adds the desktop CLI and expands the publishing, media, overlay, Roblox revenue and team workflow features. It also includes reliability and security fixes across the optional service integrations.

## Highlights

- Added the Apex Studio CLI with interactive workflows and structured JSON commands for projects, assets, publishing, Roblox uploads, Group Revenue, statistics, backups and team sync.
- Added a local overlay studio with draggable layers, reusable templates, generated preview versions and multi-image exports.
- Added a local media library with folders and tags, batch uploads, Markdown blocks and a composer preview. Publishing now handles missing images and unavailable hosting more safely.
- Expanded Roblox Group Revenue management, CSV import and statistics workflows.
- Added tracked invite campaign and optional image hosting integrations, with clearer service availability and offline behavior.
- Hardened team sync and service gateways, including TLS requirements for public gateways, scoped authorization, storage limits and cleanup of expired uploads.
- Improved ERLCX and browser handoff, project backup recovery, publishing validation and desktop layout behavior.

## Upcoming

Appearance and layout improvements are planned for an upcoming release.

## Upgrade

Run the Windows installer to install or update Apex Studio. Version `0.1.1` introduced the signed in-app updater, so existing `0.1.1` installations can install this update through **Settings → Updates** or by running the installer. Version `0.1.0` must be upgraded manually.
